# Data Science Final

## Project Overview

This project analyzes my personal tennis match data collected within the year through SwingVision. Using Python and data science techniques, I explore patterns in serving, rally length, court positioning, and shot selection to better understand which strategies contribute most to winning points.

The goal of this project is both analytical and practical: to use match data to identify strengths, weaknesses, and tactical patterns in my game.

## Research Questions

Some of the main questions explored include:

- Does my first serve win more points than my second serve?
- Which serve directions are most effective?
- Am I more successful at the baseline or at net?
- What rally lengths produce the highest win percentages?
- What shots best set up successful drop shots?
